# 白ゆりフェスタ 販売レジ

ブラウザ標準機能で動く、簡易レジと販売集計アプリです。通常のローカルモードに加え、Cloudflare Workers＋D1を使う共有モードに対応しています。画面はGitHub Pagesなどの静的ホスティングから配信できます。

共有モードの構成・設定・初回データ移行は [`cloudflare/README.md`](cloudflare/README.md) を参照してください。共有APIのURLを設定しない場合は、これまでどおり端末ごとの`localStorage`保存で動きます。

## macOSで使う

1. `index.html` と同じフォルダにあるファイル一式をMacへコピーします。
2. `index.html` をSafariまたはChromeで開きます。
3. 商品を押して数量を入力し、お預かり金額を入れて「会計を確定する」を押します。
4. 確定直後に売上、会計数、販売個数、平均会計額、商品別グラフが更新されます。

履歴の各会計には「変更」「削除」があります。「変更」で明細やお預かりを直して保存すると、同じ会計を更新できます。

共有モードを使わない場合、会計履歴と商品一覧はそのブラウザの`localStorage`に保存され、別の端末とは共有されません。共有モードでは商品・会計履歴・在庫・購入制限をCloudflare D1に保存し、ログインした端末間で同期します。

## 商品一覧の更新

商品取込はCSVまたはTSVに対応しています。ExcelまたはNumbersでは、価格表のシートを「CSV UTF-8」またはTSVとして保存してから、「管理」→「商品管理」内の「商品一覧CSVを読み込む」から読み込みます。

同梱の [products.csv](products.csv) が商品一覧の編集用ファイルです。カテゴリ、商品名、単価、アイコンを表計算ソフトで編集し、保存後に「管理」→「商品管理」内の「商品一覧CSVを読み込む」から選択してください。`index.html`を直接開く方式では、ブラウザの制限により同じフォルダのCSVを自動では読み込みません。

現在の商品一覧を保存したい場合は、「商品一覧CSVを書き出す」を使います。書き出したCSVにはカテゴリ、商品名、単価、絵文字・差し替え画像、初期アイコンのパスが含まれ、商品一覧CSVの読み込みで復元できます。

現在の当日使用版の商品は初期データとして同梱しています。園グッズ、古園服、ありがとうチケット（-50円）を含みます。

「管理」→「購入制限の設定」から、一度の会計で購入できる対象カテゴリ、きょうだい人数、1人あたりの上限を変更できます。初期値は「古園服・1人・4点」です。制限を使わない場合は「制限を適用する」をオフにしてください。共有モードでは購入制限もD1へ保存し、ローカルモードではこのブラウザに保存します。

「管理」→「商品管理」から商品の追加、単価変更、削除、アイコン差し替えができます。単価変更は各商品の「単価を保存」、削除は確認後に実行されます。商品を削除しても過去の会計履歴は残ります。商品カードには商品ごとに作成した初期アイコンを背景として表示しています。初期アイコン素材は [assets/icons](assets/icons) に商品ごとのPNGとして保存しています。差し替えた画像は共有モードではD1へ、ローカルモードではこのブラウザへ保存されます。絵文字を使う場合は `products.csv` の「アイコン」列を編集して再取込できます。

「売上・販売数」タブでは、集計期間を「今日」「今週」「今月」「全期間」から選べます。さらに分析対象時間の開始／終了時刻を指定すると、上部の集計カード、商品別・カテゴリ別・日別・時間帯別のすべてを同じ時間帯で再集計できます。時間帯別分析は表示項目・表の並び順を切り替えられ、会計がない時間を隠した表と合計行も確認できます。

次の2形式を読み込めます。

- `カテゴリ,商品名,単価`
- 既存の価格表のように、カテゴリごとに「品名,金額」の列が左右に並ぶ形式

XLSXファイルそのものは、外部ライブラリなしではブラウザ標準機能だけで安全に読むことが難しいため、直接読み込みません。ExcelからCSV UTF-8へ保存して使用してください。

## CSVの書き出し

「管理」→「会計履歴CSVを書き出す」を押すと、保存済みの会計を商品明細ごとに1行でダウンロードします。週別集計用に、会計日とその週の月曜日を示す「週開始日」を含め、会計履歴を復元するための金額情報も含めています。列は次のとおりです。

```text
会計ID,会計日時,会計日,週開始日,会計合計,お預かり,おつり,会計点数,明細番号,カテゴリ,商品名,単価,数量,売上金額
```

ExcelやNumbersでは、「週開始日」を行、「商品名」や「カテゴリ」を列またはフィルターにして、「数量」と「売上金額」を合計すると週別の商品集計ができます。カンマや引用符を含む商品名もCSVの形式が壊れないようにエスケープします。

「管理」→「会計履歴CSVを読み込む」からこのCSVを選ぶと、CSVの内容で現在の会計履歴を置き換えて復元できます。読み込み前に確認が表示されます。旧形式の集計CSVや、商品一覧CSVは会計履歴の復元には使えません。

## 履歴のバックアップと消去

定期的に「管理」→「会計履歴CSVを書き出す」でバックアップしてください。「管理」→「履歴を消去」は会計履歴だけを消し、商品一覧は残します。消去前には確認ダイアログが表示されます。

フォルダへの自動保存に対応したブラウザでは、保存先を一度選ぶと、設定した間隔で販売履歴CSVを上書き保存できます。

iPhoneなど、フォルダへの自動保存に対応していない端末では、「管理」内が「定期バックアップの通知」に切り替わります。通知を有効にして間隔を設定すると、画面を開いている間に保存のお知らせが出ます。「保存・共有」または「今すぐ保存・共有」を押し、共有メニューの「ファイルに保存」からiCloud Driveなどへ保存してください。ファイル共有に対応していない場合はCSVをダウンロードします。

画面を閉じている間やiPhoneをロックしている間に自動でファイルを書き出す機能ではありません。再び画面を表示したときに通知時刻を確認します。「あとで」を押すと、設定した間隔の後に再通知します。共有をキャンセルした場合、最終バックアップ日時は更新しません。
