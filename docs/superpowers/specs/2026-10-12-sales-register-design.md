# Shirayuri Festa レジ・販売集計アプリ 設計仕様

## 1. 目的

園グッズ・古園服などの販売で、Excelの数量入力をレジ代わりに使っている現状を、ブラウザで操作できる簡易レジに置き換える。

「確定」した会計をその場で保存し、販売数と売上を集計して画面上のグラフに反映する。会計履歴は後から、1会計1行のCSVとして出力できるようにする。

## 2. 確認済みの入力データ

添付された2つのExcelには、主に次の構造がある。

- シート「値段表」に、カテゴリ見出しと「品名」「金額」の2列ブロックが左右に並ぶ。
- カテゴリは「園グッズ」「古園服」などで、行方向に商品が続く。
- 改訂版には単価未入力の商品があるため、インポート時に未入力をエラーとして扱う必要がある。
- 当日使用版には「ありがとうチケット」単価 -50 があり、マイナス単価を許可する必要がある。
- シート「レジ」は既存の数量入力と合計・預かり・おつり計算のための表であり、新アプリではこの役割を画面と履歴に置き換える。

## 3. 成功条件

以下を、ブラウザを開くだけで行えること。

1. 商品一覧を外部ファイルから読み込める。
2. 商品を選んで数量を入力し、合計・預かり・おつりを確認できる。
3. 「確定」で1会計が履歴に追加される。
4. 確定直後に売上合計、会計数、販売個数、商品別集計が更新される。
5. 会計履歴を1会計1行のCSVで保存できる。
6. ページを閉じても、同じブラウザでは履歴と商品一覧が残る。

## 4. 採用アーキテクチャ

依存を最小限にした静的なSPAとする。

- `index.html`: 画面の骨格とアクセシブルな操作部品
- `styles.css`: レスポンシブなレジ画面と集計画面のスタイル
- `app.js`: 商品インポート、カート、会計確定、永続化、集計、CSV出力
- `products.default.js`: 添付された当日使用版を初期表示できるようにした初期商品一覧

外部ライブラリ、npmパッケージ、CDN、OSSコードは使わず、ブラウザ標準のFile API、`localStorage`、`Blob`、SVGだけで実装する。サーバーやデータベースは使わず、商品一覧と会計履歴は `localStorage` に保存する。ブラウザの安全制限により、確定のたびに任意のCSVファイルへ自動追記はせず、履歴を保存した上で「CSVを書き出す」操作から最新のCSVをダウンロードする。

## 5. データモデル

### 商品

```text
Product {
  id: string                 // category + name から安定生成
  category: string
  name: string
  unitPrice: number          // 0以上またはマイナスを許可
}
```

### 会計

```text
Transaction {
  id: string                 // 生成時刻と乱数で一意化
  recordedAt: string         // ISO 8601
  total: number
  received: number
  change: number
  itemCount: number          // 数量の合計。割引・チケットは数量として数える
  items: [
    {
      category: string
      name: string
      unitPrice: number
      quantity: number
      subtotal: number
    }
  ]
}
```

## 6. 商品インポート仕様

ファイル選択で `.csv` と `.tsv` を受け付ける。ExcelまたはNumbersで「値段表」シートをCSV UTF-8として保存してから読み込む。現在の添付Excelの内容は通常のJavaScriptデータスクリプトとして初期商品データに同梱する。JSON fetchやES module fetchに依存しないため、`index.html` を直接開いても初期商品を表示できる。

CSV/TSVは、現在の価格表のようにカテゴリ見出しと「品名」「金額」の列が左右に並ぶ形式、および正規化された「カテゴリ」「商品名」「単価」の3列形式の両方に対応する。ブラウザ標準のテキスト読込だけを使うため、XLSXの直接読込は対象外とする。

### CSV

次の日本語・英語のヘッダーを許可する。

- カテゴリ: `カテゴリ`, `分類`, `category`
- 商品名: `商品名`, `品名`, `name`, `product`
- 単価: `単価`, `金額`, `価格`, `price`, `unitPrice`

ヘッダーがない場合は `カテゴリ,商品名,単価` の順で解釈する。数値として読めない単価は除外し、取込結果に警告を出す。カテゴリと商品名の組み合わせが重複する場合は最後の行を採用し、重複件数を警告する。

インポート成功後は商品一覧を置き換えるが、会計履歴は消さない。現在の一覧を残したまま追加する操作はMVPの範囲外とする。

## 7. 画面と操作

### レジ画面

- 上部に「商品取込」「CSV書き出し」「履歴消去」を配置する。
- 商品はカテゴリごとのセクションに分け、商品名、単価、数量ステッパーを表示する。
- 商品ボタンを押すと数量を1増やす。`−`, 数量入力, `＋` で直接調整できる。
- 右側または下部の会計パネルに、選択商品、数量、小計、合計を表示する。
- 「お預かり」入力、合計金額と同額を入れるクイック操作、おつりを表示する。
- カートが空、または預かりが不足している場合は「確定」を無効にする。
- 確定後は会計パネルを空にし、入力された会計を保存して集計を更新する。

### 集計画面

- 売上合計
- 会計数
- 販売個数
- 商品別の販売数量ランキング
- 商品別売上の棒グラフ
- カテゴリ別売上の集計
- 「今日」「全期間」の表示切替

グラフは外部チャートライブラリを使わず、HTML/CSSまたはSVGで描画する。販売数が0の商品はランキングに表示しない。

### 履歴・CSV

画面内に直近の会計履歴を表示する。CSVには次の列を出力する。

```text
会計ID,会計日時,合計,お預かり,おつり,商品点数,明細
```

「明細」は1セルにまとめ、カテゴリ、商品名、数量、単価、小計を含める。CSVのセルはRFC 4180に合わせて引用符と改行をエスケープする。

## 8. 状態管理とエラー処理

- `localStorage` の読み込みに失敗、または壊れたデータの場合は空の状態に戻し、画面上に再読み込みを促す注意を表示する。
- 商品ファイルが不正、対象シートがない、取込可能な商品が0件の場合は商品一覧を置き換えず、エラーを表示する。
- 会計確定後に保存に失敗した場合は、カートを消さず、再試行できるようにする。
- 履歴消去は確認ダイアログを必須にする。商品一覧は消去しない。
- 合計がマイナスになった場合は確定を許可せず、商品とチケットの組み合わせを見直すメッセージを出す。

## 9. テスト方針

ビジネスロジックはDOMから分離し、次を自動テストする。

- CSV/TSVの左右2ブロックから商品を抽出できる。
- 日本語・英語のCSVヘッダーを解釈できる。
- マイナス単価を取り込める。
- 単価未入力・不正な単価を除外して警告件数を返せる。
- 数量と単価から小計・合計・おつりを計算できる。
- 1会計を1行のCSVに変換でき、明細内のカンマや引用符を壊さない。
- 会計確定後に商品別・カテゴリ別の集計が正しく更新される。

ブラウザ上では、商品取込、数量変更、預かり入力、確定、集計更新、CSVダウンロードまでを手動確認する。

## 10. MVPの対象外

- 複数端末でのリアルタイム共有
- ユーザー認証、権限管理
- 在庫数の減算・在庫切れ管理
- 会計の編集や返品処理
- 確定操作ごとのファイル自動追記
- 複数の価格表を同時に保持する切替機能
